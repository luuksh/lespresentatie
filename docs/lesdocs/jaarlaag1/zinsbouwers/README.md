# Zinsbouwers

Project voor brugklas vwo over grammatica en taalkunde.

## Bestanden

- `projectplan-zinsbouwers.md`: docentversie met opzet, leerlijn, toetsroutine en beoordelingslogica.
- `netschrift-zinsbouwers.md`: leerlingversie voor in het netschrift.
- `lespresentaties-zinsbouwers.md`: korte lesslides per les.
- `presentatievormen-zinsbouwers.md`: werkvormen die leerlingen tijdens de vrije fase kunnen kiezen.
- `toetsmomenten-zinsbouwers.md`: toetsformat en voorbeeldvragen per niveau.
- `afvinkkaart-zinsbouwers.md`: leerlingkaart om zinsdelen en woordsoorten zichtbaar af te vinken.
