## Bewijs

Een onderdeel is pas echt afgevinkt als je er bewijs bij hebt.

Bewijs kan zijn:

- een goed gemaakte toetsvraag;
- een eigen voorbeeldzin met uitleg;
- een verbeterde fout;
- een uitleg die een klasgenoot begrijpt;
- een korte presentatievorm uit de vrije werkfase.
